# 🛠️ [CTF-Tool]

📝 **[CTF Tool]** is a custom automated script designed for Capture The Flag (CTF) competitions and ethical hacking. It automates the initial phases of penetration testing, including reconnaissance, directory enumeration, and vulnerability scanning, saving valuable time during time-constrained CTF events.

### ✨ Key Features
* 🔍 **Automated Reconnaissance:** Runs initial Nmap scans to identify open ports and services.
* 📂 **Directory Brute-forcing:** Automatically integrates with tools like DIRB or ffuf for hidden directory discovery.
* 🌐 **Subdomain Enumeration:** Quickly finds active subdomains for web-based challenges.
* ⚡ **Fast & Lightweight:** Optimized for quick execution in Kali Linux environments.
